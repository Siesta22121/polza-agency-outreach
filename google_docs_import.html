Как импортировать

Google Sheets (таблица с компаниями)

  1. Открой sheets.new
  2. Файл → Импортировать → Загрузить → выбери base_companies.csv
  3. Готово — 57 компаний с персонализацией

Google Docs (отчёт)

  1. Открой docs.new
  2. Файл → Открыть → Загрузить → выбери этот HTML-файл (google_docs_import.html)
  3. Или просто открой HTML в браузере, Ctrl+A, Ctrl+C, вставь в Google Docs
