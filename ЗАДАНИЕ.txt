Альтернатива: Скрипт для автоматической персонализации
text
Если ты можешь писать код, создай Python-скрипт для автоматической персонализации:

ТРЕБОВАНИЯ К СКРИПТУ:
1. Читает Google Таблицу с базой компаний
2. Для каждой компании отправляет запрос к OpenAI API
3. Промпт: "Найди конкретный факт о компании {name} ({url}) для персонализации холодного письма"
4. Сохраняет результат в столбец "Персонализация"
5. Обрабатывает ошибки (если сайт недоступен, ставит "Не удалось найти факт")

ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ:
- Используй библиотеки: pandas, openai, requests, beautifulsoup4, gspread
- Не храни API-ключи в коде (используй переменные окружения)
- Добавь задержки между запросами (2 секунды)
- Логируй прогресс (какая компания обрабатывается)

ПРИМЕР КОДА:
```python
import openai
import pandas as pd
import time

def get_personalization(company_name, url):
    prompt = f"Найди конкретный факт о компании {company_name} ({url}) для персонализации холодного письма. Ответь одним предложением."
    response = openai.ChatCompletion.create(
        model="gpt-4o-mini",
        messages=[{"role": "user", "content": prompt}]
    )
    return response.choices[0].message.content

# Основной цикл
df = pd.read_csv('companies.csv')
for index, row in df.iterrows():
    try:
        fact = get_personalization(row['Название'], row['Сайт'])
        df.at[index, 'Персонализация'] = fact
        print(f"✅ {row['Название']} - OK")
    except Exception as e:
        df.at[index, 'Персонализация'] = f"Ошибка: {e}"
        print(f"❌ {row['Название']} - {e}")
    time.sleep(2)
df.to_csv('companies_with_personalization.csv', index=False)
